# IDD Intent Index

Текущие продуктовые спецификации. Идентификатор разрешается в единственный файл `IDD-NNNN.*.md`; документы являются нормативными, индекс служит для поиска.

| Document | Role | Area | Notes |
| --- | --- | --- | --- |
| IDD-0001 | Spec | Обзор и границы MVP | Платформа, безопасность, приоритеты и non-goals |
| IDD-0002 | Spec | Экземпляры и закрепления | Общая идентичность, учёт процессов, соответствие кнопкам |
| IDD-0003 | Spec | Панель и поиск | Visual Intent, клики, меню, каталог приложений |
| IDD-0004 | Spec | Запуск экземпляров | Подтверждение нового PID, параллельность и ошибки |
| IDD-0005 | Spec | Окна и разрешения | Accessibility, деградация, запрет Screen Recording |
| IDD-0006 | Spec | Рабочий стол macOS | Dock, мониторы, Spaces, fullscreen и выход |
| IDD-0007 | Spec | Настройки и данные | Сохранение, миграции, закрепления и автозапуск |
| IDD-0008 | Spec | Качество и поставка | Производительность, доступность, приватность и приёмка |
| IDD-0009 | Spec | Скрытие системного Dock | Добровольный режим, транзакция предпочтений и аварийное восстановление |
