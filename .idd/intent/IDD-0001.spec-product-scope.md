# IDD-0001.spec-product-scope

## Назначение

WMac! — нативная панель задач для macOS 14 Sonoma и новее, по виду и основным сценариям похожая на Windows 11. Она заменяет Dock в повседневной работе, сохраняя системный Dock доступным. Поддерживаются Apple Silicon и Intel универсальной сборкой; распространение — через GitHub Releases в DMG вне Mac App Store. Developer ID, notarization и stapling для MVP не требуются; условия первого запуска определены в IDD-0008.

Главный приоритет MVP — надёжный учёт процессов и запуск дополнительных экземпляров. Каждый подходящий GUI-процесс представлен собственной кнопкой на каждой видимой панели; несколько окон одного процесса не создают дополнительные кнопки. Обычный клик выбирает конкретный экземпляр; Shift + левый клик запрашивает новый независимый процесс. Внешние эффекты не должны осложнять эти функции.

Отдельный процесс не означает отдельный профиль, папку данных, cookies или независимые настройки: это определяет стороннее приложение. WMac не обещает изоляцию данных или принудительный обход single-instance политики.

## Границы и безопасность

Используются только публичные API Apple. Запрещены private API, внедрение в Dock, изменение SIP, отключение безопасности macOS, системных горячих клавиш и перехват системных кликов. Обработка модификаторов клика ограничена кнопками WMac.

В MVP не входят отдельные кнопки каждого окна, preview/thumbnail и Screen Recording, замена menu bar, Control Center, системного трея или Notification Center, полноценный Start с рекомендациями, виджетами и индексацией документов, гарантированная сортировка процессов по Space/дисплею, копирование приложений для обхода single-instance ограничений, системное резервирование области экрана и автоматическое изменение размеров чужих окон. Также исключены облачная синхронизация, аналитика, плагины, автоматическое обновление и автоматический откат.

## Связанные спецификации

IDD-0002 определяет идентичность процессов и закреплений; IDD-0003 — интерфейс; IDD-0004 — новый запуск; IDD-0005 — окна и разрешения; IDD-0006 — сосуществование с системой; IDD-0007 — настройки; IDD-0008 — качество и поставку.

## Приёмка и проверка

На macOS 14+ приложение открывается без Terminal, показывает панель и обнаруживает уже работающие экземпляры. Основные сценарии доступны без изменения системной безопасности. Выполнение MVP подтверждается свойствами и сценариями связанных спецификаций, включая три независимых процесса тестового приложения и корректную деградацию при отсутствии Accessibility.
