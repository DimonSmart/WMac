# IDD-0007.spec-settings-and-storage

## Intent

Локальные настройки управляют панелью и переживают перезапуск и обновление приложения без сохранения временных идентификаторов процессов и окон.

## Разделы настроек

- «Общие»: единый переключатель запуска при входе в macOS (переход к системным Login Items только если требуется подтверждение или произошла ошибка), панели на всех экранах или основном, открытие настроек Dock, явный opt-in режим временного скрытия Dock по IDD-0009.
- «Вид»: высота 40–64 pt с исходным значением 52 pt, светлая/тёмная/системная тема, подписи только в tooltip, прозрачность в ограниченном диапазоне.
- «Поведение»: Shift + клик всегда запрашивает новый экземпляр и не отключается в MVP; средний клик настраивается и по умолчанию включён; сворачивание окна кликом по активному экземпляру включается/отключается; глобальные сочетания для расположения текущего окна включаются и отключаются одним параметром и по умолчанию выключены.
- «Приложения»: закреплённые приложения, их порядок, исключения из списка для пользовательских приложений и сброс настроек.
- «Разрешения»: состояние Accessibility, объяснение отсутствующих функций и открытие системных настроек.

Хранилище восстановления Dock независимо от settings.json и не должно терять состояние при повреждении обычных настроек. Схема settings.json — v3; v1/v2 мигрируют с выключенным hideSystemDock.

## Хранение

Настройки сохраняются атомарно в `~/Library/Application Support/WMac/`, со схемой версии и миграцией. Закрепления и порядок переживают обновление и перезапуск. При необходимости сохраняется bookmark URL приложения. PID, Window ID, временные Accessibility-ссылки и исходная геометрия окон для команды восстановления между сессиями не сохраняются. Пользовательские настройки не отправляются в сеть.

Истёкший или невалидный bookmark и восстановление настроек обрабатываются без падения; отсутствующее приложение сохраняет объяснимую запись и действия восстановления по IDD-0002.

## Приёмка и проверка

Проверяются изменение доступных настроек, запуск при входе через интерфейс, сохранение Pin и порядка, повторный старт, миграция версии и атомарное сохранение. Проверяются невалидный bookmark и восстановление настроек; сохранённые данные не содержат временных PID, Window ID и AX-ссылок.

Связанные спецификации: IDD-0002, IDD-0003, IDD-0005, IDD-0006. Численные пределы прозрачности и исходное значение опции сворачивания в ТЗ не определены; импорт не устанавливает их.

## Расширение настроек — IDD-0010

Схема settings.json — v4. Версии v1/v2/v3 мигрируют с сохранением закреплений и системного Dock. Поля: hoverPreviews (automatic/always/disabled; по умолчанию automatic), showWindowThumbnails (по умолчанию true, но без автоматического запроса Screen Recording), appPreviewPreferences (опциональное always/disabled для AppDefinition), windowArrangementShortcuts (по умолчанию false). В старых файлах поле сочетаний считается выключенным. Временные идентификаторы окон и процессов не сохраняются.

## Упрощение навигации и меню

- Меню строки macOS и кнопки управления WMac содержат показ/скрытие панели, настройки, About, справку и выход. Отдельное главное меню приложения предоставляет стандартные команды About, Settings, Help, Quit; меню управления не дублирует списки закреплений, настройки разрешений или ссылки на системные настройки Dock.
- Список закреплений редактируется через контекстное меню кнопки панели или компактные действия в разделе «Приложения» (порядок, открепление, восстановление пути). Контекстное меню процесса показывает единый пункт «Окна…»: карточки окон работают также без Screen Recording, показывая текстовые варианты, если миниатюры недоступны.
- В настройках «Разрешения» всегда виден статус Accessibility; когда доступ не предоставлен, одна кнопка открывает соответствующий раздел System Settings. Первое обращение к функциям управления окнами по-прежнему может вызвать системный запрос Accessibility (IDD-0005). Кнопка повторной ручной проверки статуса не требуется: состояние обновляется при возвращении WMac в фокус.
- В «Общих» отсутствуют команды выхода из приложения и повторный вызов Dock guidance. Справка доступна из меню WMac. В меню управления должны сохраняться условные аварийные команды восстановления Dock и повторной операции с закреплениями.
- Обычные информационные уведомления не добавляют пунктов меню; ошибки восстановления доступны через соответствующие специализированные команды и экраны. Обновление Settings сохраняет активную вкладку, положение прокрутки и, если возможно, фокус ввода.
