# IDD-0007.spec-settings-and-storage

## Intent

Локальные настройки управляют панелью и переживают перезапуск и обновление приложения без сохранения временных идентификаторов процессов и окон.

## Разделы настроек

- «Общие»: единый переключатель запуска при входе в macOS (переход к системным Login Items только если требуется подтверждение или произошла ошибка), панели на всех экранах или основном, открытие настроек Dock, явный opt-in режим временного скрытия Dock по IDD-0009.
- «Вид»: высота 40–64 pt с исходным значением 52 pt, светлая/тёмная/системная тема, подписи только в tooltip, прозрачность в ограниченном диапазоне.
- «Поведение»: Shift + клик всегда запрашивает новый экземпляр и не отключается в MVP; средний клик настраивается и по умолчанию включён; сворачивание окна кликом по активному экземпляру включается/отключается; глобальные сочетания для расположения текущего окна включаются и отключаются одним параметром и по умолчанию выключены; отдельный выключенный по умолчанию переключатель разрешает автоматическую коррекцию обычных максимизированных и плиточных окон у панели WMac через Accessibility (IDD-0005).
- «Предпросмотр окон»: общие параметры наведения и миниатюр, а также переопределения для отдельных приложений.
- «Разрешения»: состояние Accessibility, объяснение отсутствующих функций и открытие системных настроек.

Отдельной вкладки «Приложения» нет. Закрепить или открепить приложение и восстановить его путь можно через контекстное меню кнопки панели; порядок кнопок меняется перетаскиванием или командами контекстного меню. Пользовательские исключения, скрывающие приложение и его закрепление с панели, не поддерживаются. Общий сброс настроек доступен в разделе «Общие» и не затрагивает закрепления, их порядок или регистрацию запуска при входе.

Хранилище восстановления Dock независимо от settings.json и не должно терять состояние при повреждении обычных настроек.

## Хранение

Настройки сохраняются атомарно в `~/Library/Application Support/WMac/`, со схемой версии и миграцией. Закрепления и общий относительный порядок иконок переживают обновление и перезапуск. `pins.json` использует схему v3 с массивом логических слотов для закреплений и незакреплённых приложений, а также атомарной миграцией из v1/v2; устаревшие временные процессы не сохраняются. Слоты без работающего процесса остаются в хранилище, но не занимают место в UI. При необходимости сохраняется bookmark URL приложения. PID, Window ID, временные Accessibility-ссылки и исходная геометрия окон для команды восстановления между сессиями не сохраняются. Пользовательские настройки не отправляются в сеть.

Истёкший или невалидный bookmark и восстановление настроек обрабатываются без падения; отсутствующее приложение сохраняет объяснимую запись и действия восстановления по IDD-0002.

## Приёмка и проверка

Проверяются изменение доступных настроек, запуск при входе через интерфейс, сохранение Pin и порядка перетаскиванием и контекстным меню, управление закреплениями из контекстного меню, повторный старт, миграция версии и атомарное сохранение. При миграции прежние исключения приложений больше не скрывают приложения. Проверяются невалидный bookmark и восстановление настроек; сохранённые данные не содержат временных PID, Window ID и AX-ссылок.

Связанные спецификации: IDD-0002, IDD-0003, IDD-0005, IDD-0006. Численные пределы прозрачности и исходное значение опции сворачивания в ТЗ не определены; импорт не устанавливает их.

## Расширение настроек — IDD-0010

Схема settings.json — v5. Версии v1–v4 мигрируют с сохранением поддерживаемых настроек; прежние исключения приложений отбрасываются, чтобы старые данные не продолжали скрывать приложения. Скрытие системного Dock при миграции не включается без явного согласия. Поля: hoverPreviews (automatic/always/disabled; по умолчанию automatic), showWindowThumbnails (по умолчанию true, но без автоматического запроса Screen Recording), appPreviewPreferences (опциональное always/disabled для AppDefinition), windowArrangementShortcuts (по умолчанию false), reserveTaskbarSpace (по умолчанию false). В старых файлах поле сочетаний считается выключенным. Временные идентификаторы окон и процессов не сохраняются.

## Упрощение навигации и меню

- Меню строки macOS и кнопки управления WMac содержат показ/скрытие панели, настройки, About, справку и выход. Отдельное главное меню приложения предоставляет стандартные команды About, Settings, Help, Quit; меню управления не дублирует списки закреплений, настройки разрешений или ссылки на системные настройки Dock.
- Список закреплений редактируется через контекстное меню кнопки панели; порядок также меняется перетаскиванием. Контекстное меню процесса показывает единый пункт «Окна…»: карточки окон работают также без Screen Recording, показывая текстовые варианты, если миниатюры недоступны.
- В настройках «Разрешения» всегда виден статус Accessibility; когда доступ не предоставлен, одна кнопка открывает соответствующий раздел System Settings. Первое обращение к функциям управления окнами по-прежнему может вызвать системный запрос Accessibility (IDD-0005). Кнопка повторной ручной проверки статуса не требуется: состояние обновляется при возвращении WMac в фокус.
- В «Общих» отсутствуют команды выхода из приложения и повторный вызов Dock guidance. Справка доступна из меню WMac. В меню управления должны сохраняться условные аварийные команды восстановления Dock и повторной операции с закреплениями.
- Обычные информационные уведомления не добавляют пунктов меню; ошибки восстановления доступны через соответствующие специализированные команды и экраны. Обновление Settings сохраняет активную вкладку, положение прокрутки и, если возможно, фокус ввода.
