# ENG-0001.rule-native-macos-stack

## Rule

Реализация WMac использует Swift и AppKit как нативный macOS App target в Xcode, с deployment target macOS 14.0 и минимизацией внешних зависимостей. UI панели использует AppKit, NSPanel, NSVisualEffectView и системные NSImage; настройки представлены обычным отдельным окном.

Взаимодействие с системой ограничено публичными Apple API. Запрещены приватные SkyLight API и внедрение в Dock.

## Applicability

Always
