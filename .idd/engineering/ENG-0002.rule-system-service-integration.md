# ENG-0002.rule-system-service-integration

## Rule

Начальное состояние процессов получают из `NSWorkspace.shared.runningApplications`. Монитор подписывается через `NSWorkspace.shared.notificationCenter` на запуск, завершение, активацию, деактивацию, скрытие и восстановление приложений. Редкая сверка снимка исправляет пропущенные события, выполняется также после пробуждения и возвращения с экрана блокировки. Интервал конфигурируется внутри сервисов; непрерывный высокочастотный опрос не допускается. Пример пяти секунд не устанавливает обязательное численное значение.

Для переключения используется конкретный `NSRunningApplication`, а не открытие по bundle ID. Таблица экземпляров использует `(PID, processStartTime)` и стабильные UI-идентификаторы на время жизни процесса. В качестве `processStartTime` используется `NSRunningApplication.launchDate`, если она доступна; иначе время старта читается через публичный libproc `proc_pidinfo(PROC_PIDTBSDINFO)` из `pbi_start_tvsec` и `pbi_start_tvusec`, с проверкой возвращённого PID. Один resolver применяется при построении снимка и при повторной проверке процесса перед действиями, включая Accessibility. Если ни один источник не даёт надёжного времени старта, процесс не добавляется в управляемый снимок; PID без проверки времени жизни не используется.

Для нового экземпляра используется `NSWorkspace.shared.openApplication(at:configuration:completionHandler:)` с точным bundle URL и `NSWorkspace.OpenConfiguration`, где `createsNewApplicationInstance = true`, `activates = true`. Перед запросом фиксируются PID соответствующей AppDefinition; возвращённый `NSRunningApplication` сверяется с обновлённым списком процессов, подтверждая новый PID. Параллельные запросы не объединяются, каждый имеет отдельный результат success/error/unconfirmed.

Операции окон реализуются через публичные `AXUIElement` и `AXObserver`. Недокументированное сопоставление `AXUIElement` и `CGWindowID` не используется. Геометрия дисплеев берётся из `NSScreen`; `NSWindow.CollectionBehavior` применяется только в пределах публичного API. Запуск при входе реализуется через `SMAppService.mainApp`.

## Applicability

Conditional

## Applies when

Реализация или изменение обнаружения процессов, запуска экземпляров, управления окнами, геометрии панелей или запуска при входе.
